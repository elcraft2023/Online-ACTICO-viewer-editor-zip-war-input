📖 Anleitung & Hilfe

Bedienung:

  • ZIP / WAR laden: Datei klicken oder ins gestrichelte Feld ziehen, dann links eine .vrrule wählen.
  • Call-Knoten (↗): Klick öffnet die verknüpfte Regel. Fehlt sie → Fehlermeldung. Shift+Klick = bearbeiten.
  • Knoten klicken: Bearbeiten-Dialog (Label, Expression, löschen, Kindknoten).
  • Leere Fläche ziehen: Canvas verschieben (Pan).
  • Zoom (+ / − / 100 %): Vergrößern, verkleinern, Ansicht zurücksetzen.
  • ACTICO + XML: Beide aktiv = Split; einen Button nochmal klicken = Einzelansicht.
  • ＋ Knoten: Palette oben öffnen (Decide, Assign, Action, Call, + Branch).
  • Content View: Ein = Expressions/Bedingungen sichtbar; Aus = nur Kurztitel an den Knoten.
  • Kontext: Panel mit Ein-/Ausgaben (bleibt sichtbar, auch über dem Flow).
  • Zoom: Mausrad über dem Flow (zoomt zur Zeigerposition, stufenlos bis ~2 %). Toolbar − / % / + ebenfalls.
  • ↩ / ↪: Rückgängig / Wiederherstellen (auch Ctrl/Cmd+Shift+Z bzw. Ctrl/Cmd+Shift+Y).
  • Farben: Grün Start · Gelb Decide · Blau Assign · Grün Call/Action · Rot Ende
